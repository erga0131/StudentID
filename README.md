#StudentID
某大学の学籍番号に関するウワサを検証するリポジトリ

## check_studentid.py
### 概要
学籍番号の上7桁を入力した時、最後の1桁を計算するスクリプト。 
### 実行
```bash
pip install numpy
python3 check_studentid.py
```
### 仕様
最後の一桁はModulus11で計算されたチェックデジットになっている。※1  
すなわち、1,2,3,4,5,6,7桁目にそれぞれ2,3,4,5,6,7,8をかけた値を足し、11で割った余りを11から引くものである。ただし、余り0のときは1、余り1のときは0になる。  
このプログラムでは重みと上7桁をそれぞれベクトルにして内積を取ることで計算している。
※1[https://x.com/crich_keio2026/status/2037303585713615187](https://x.com/crich_keio2026/status/2037303585713615187)


## gen_studentid.py
### 概要
付番規則に沿った学籍番号を生成するスクリプト。
### 実行
```bash
pip install numpy
python3 gen_studentid.py
```
### 仕様
1桁目が学部ごとの番号である。ここでは1~7の間で乱数を取る。  
2,3桁目が入学年度である。ここでは2020〜2029年の間になるよう乱数を取る。  
4~7桁目が学部ごとの付番であり、規則が不明なため完全に4桁の乱数を取っている。  
8桁目は先述のチェックデジットなので、上記7桁からModulus11で計算している。
